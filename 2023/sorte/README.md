# Sorteios

Projeto de estudos em HTML, CSS e JavaScript para sorteio de nomes e números.

## Arquivos
- `index.html`: página inicial.
- `sorteio-nomes.html`: sorteio de nomes.
- `sorteio-numeros.html`: sorteio de números.
- `main.js`: lógica JavaScript.
- `style.css`: estilos.

## Como executar
Abra `index.html` no navegador. Não há etapa de build configurada.

> Projeto migrado para o monorepositório de estudos. O histórico de edição do VS Code e arquivos gerados não foram incluídos.
