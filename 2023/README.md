## Regras de organização

- Cada projeto fica em sua própria pasta local neste repositório.
- READMEs podem apontar para demonstrações publicadas (Netlify, Vercel etc.), mas não para os antigos repositórios GitHub.
- Não copiar históricos de editor, dependências geradas ou segredos.
- **Não excluir os repositórios originais até concluir a migração e conferir os recursos ausentes.**
