# 2025 — Projetos e experimentos

Use esta seção para projetos de 2025, diferenciando:

- **Projeto completo:** possui objetivo claro, execução documentada e código relevante.
- **Protótipo:** demonstra uma ideia ou interface, sem pretensão de produção.
- **Exercício:** prática curta de uma tecnologia ou conceito.
- **Experimento com IA/Copilot:** código produzido ou modificado durante um estudo assistido por IA.

Para cada item, registrar o que foi escrito por você, o que foi gerado/assistido por IA e o que foi validado manualmente. Não publicar segredos ou código de empresa sem autorização.
