# Catálogo de repositórios

O arquivo `repositorios.csv` é o inventário inicial. Preencha-o com dados reais da conta e revise cada linha antes de decidir importar, arquivar ou tornar algo privado.

## Campos

- `name`: nome exato do repositório.
- `url`: URL de origem.
- `visibility`: público/privado.
- `created_at`: data de criação registrada pelo GitHub.
- `updated_at`: última atualização registrada.
- `periodo_estimado`: só preencher após analisar datas e contexto.
- `categoria`: curso técnico, projeto, exercício, Copilot, Microsoft Learn, profissional, duplicado ou revisar.
- `acao`: manter original, referenciar, importar após revisão, tornar privado ou arquivar após decisão manual.
- `observacoes`: alertas de segurança, duplicatas ou dúvidas.

**Não** use a data de criação do repositório como única prova de quando o código foi feito: um repositório pode ter sido criado/importado depois.
