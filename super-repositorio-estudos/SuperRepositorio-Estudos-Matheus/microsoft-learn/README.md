# Guia de Estudos — Microsoft Learn

Use este diretório para organizar módulos concluídos, anotações próprias e pequenos laboratórios de estudo.

## Como registrar cada módulo

```markdown
## Nome do módulo ou learning path

- **Link oficial:** URL do Microsoft Learn
- **Data de estudo:** AAAA-MM-DD
- **Objetivos:** conceitos que o módulo promete ensinar
- **Anotações próprias:** resumo em suas palavras
- **Laboratório:** o que foi praticado
- **Dúvidas:** o que precisa de revisão
- **Status:** não iniciado / em andamento / concluído
```

## Áreas sugeridas

- Git e GitHub;
- fundamentos de desenvolvimento e controle de versão;
- segurança de aplicações;
- Azure e fundamentos de cloud, se alinhados aos objetivos;
- IA generativa e ferramentas de desenvolvimento;
- práticas de engenharia, testes e DevOps.

Catálogo oficial: https://learn.microsoft.com/training/
