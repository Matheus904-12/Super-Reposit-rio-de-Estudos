# 2023–2024 — Curso Técnico

Espaço destinado aos trabalhos feitos durante o curso técnico de Desenvolvimento de Sistemas.

## Critérios de organização

- Preservar o código e os nomes originais quando possível.
- Agrupar por assunto (HTML/CSS, JavaScript, PHP, banco de dados, orientação a objetos, jogos, Figma/UI etc.) somente depois de verificar o conteúdo real.
- Registrar a atividade ou objetivo, quando conhecido.
- Identificar claramente trabalhos em dupla/grupo e respeitar a autoria.
- Não declarar tecnologias ou funcionalidades sem conferir os arquivos.

## Ficha sugerida para cada projeto

```markdown
## Nome do projeto

- **Repositório original:** URL
- **Período:** mês/ano ou intervalo aproximado
- **Contexto:** disciplina, atividade ou projeto técnico
- **Tecnologias:** confirmar nos arquivos
- **O que aprendi:** preencher com informações verdadeiras
- **Estado:** exercício, demonstração, incompleto ou concluído
```

Os trabalhos antigos são parte da trajetória de aprendizagem; não precisam ser apagados por não serem projetos profissionais atuais.
