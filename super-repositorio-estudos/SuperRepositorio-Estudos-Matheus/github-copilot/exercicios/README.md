# Exercícios do Copilot

Guarde aqui exercícios curtos, com entrada, objetivo e resultado revisado. Não use este diretório para despejar respostas geradas sem validação.

Sugestões:
- explicar código legado;
- criar testes unitários para uma função pequena;
- encontrar e corrigir um bug reproduzível;
- refatorar uma função sem alterar comportamento;
- gerar documentação a partir de código confirmado;
- revisar uma consulta SQL quanto a parâmetros e validação.
