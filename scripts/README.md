# Scripts de manutenção do catálogo

Esta pasta pode receber scripts pequenos para validar links, conferir o formato do CSV ou gerar relatórios do catálogo.

Antes de adicionar um script:
- documente os pré-requisitos e como executá-lo;
- não inclua tokens ou credenciais;
- evite operações destrutivas por padrão;
- valide a saída antes de usá-la para alterar repositórios;
- mantenha a classificação manual quando os metadados não forem suficientes.
