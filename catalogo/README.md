# Catálogo de repositórios

O catálogo aponta para os projetos originais do GitHub e ajuda a organizar o histórico sem duplicar o código.

## Arquivo de dados

O arquivo [repositorios.csv](repositorios.csv) é o índice inicial e será preenchido após o inventário dos repositórios e a verificação dos metadados. Campos previstos:

- **nome:** nome do repositório.
- **url:** link para o repositório original.
- **periodo:** período confirmado ou a-classificar.
- **categoria:** curso técnico, projeto, experimento, Copilot, Microsoft Learn ou outro.
- **linguagem:** linguagem principal confirmada, se disponível.
- **status:** ativo, arquivado, protótipo, exercício ou a revisar.
- **observacoes:** contexto breve e verificável.

## Regras de classificação

Não deduza o período apenas pelo nome do projeto. Se a data ou o contexto não estiverem confirmados, marque como a-classificar e revise manualmente. Repositórios de terceiros devem ser identificados como referências, não como trabalhos autorais.
