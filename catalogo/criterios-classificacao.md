# Critérios para classificar o catálogo

O arquivo repositorios.csv é um inventário inicial dos repositórios públicos encontrados na conta. Ele não afirma que todos estão prontos para portfólio.

## Estados recomendados
- **A classificar:** nome e URL registrados; conteúdo ainda não revisado.
- **Estudo/curso:** exercício, aula, laboratório ou material de aprendizagem.
- **Experimento:** protótipo ou prova de conceito.
- **Projeto acadêmico:** atividade vinculada a curso ou disciplina.
- **Projeto de portfólio:** executável/documentado, com escopo claro e revisão de segurança.
- **Arquivado:** repositório arquivado no GitHub; preservar como histórico.

## Próxima revisão por repositório
1. Abrir o README e identificar objetivo, stack e período.
2. Conferir arquivos e commits antes de atribuir uma data ou categoria.
3. Verificar se existem credenciais, tokens, .env, dados pessoais ou dumps.
4. Confirmar instruções de instalação e execução.
5. Identificar testes e limitações.
6. Preencher a coluna status e uma nota curta com evidências.

## Proteção da história
- Não copiar automaticamente todos os códigos para este repositório.
- Manter os repositórios originais como fonte de verdade e linkar para eles.
- Não expor repositórios privados no catálogo público.
- Se um segredo já foi publicado, revogá-lo/rotacioná-lo; apagar do arquivo atual não remove cópias do histórico Git.
- Não declarar um projeto seguro apenas por não encontrar credenciais numa leitura rápida.
