# Projetos e experimentos — 2025

Esta seção reúne links e notas sobre projetos posteriores ao período de 2023–2024. Projetos completos continuam em seus próprios repositórios; aqui ficam o índice, o contexto e o que foi aprendido.

## Critérios de inclusão

- Projeto com objetivo identificável.
- Experimento técnico útil para revisitar.
- Protótipo que demonstre uma tecnologia ou conceito.
- Exercício relevante, identificado claramente como exercício.

## Modelo de registro

- **Nome e link original**
- **Objetivo**
- **Stack confirmada**
- **O que foi implementado**
- **O que aprendi**
- **Estado atual:** concluído, protótipo, arquivado ou precisa de revisão
- **Próxima melhoria**
