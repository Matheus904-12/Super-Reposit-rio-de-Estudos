# Exercícios práticos de GitHub Copilot

Cada exercício deve produzir uma alteração pequena, testável e compreendida. Use Java como linguagem principal sempre que possível; outras linguagens podem ser usadas quando o material oficial exigir.

## Exercício 1 — Explicar antes de alterar

1. Escolha uma classe Java pequena.
2. Peça ao Copilot para explicar responsabilidades, entradas, saídas e possíveis falhas.
3. Confira as afirmações diretamente no código.
4. Registre uma afirmação correta e outra que precisou de correção.

## Exercício 2 — Escrever testes

1. Escolha um método com comportamento claro.
2. Peça casos de teste para sucesso, limites e falhas.
3. Revise se os casos testam comportamento, não apenas repetem a implementação.
4. Execute os testes e anote o resultado.

## Exercício 3 — Refatoração controlada

1. Escolha uma melhoria pequena e delimitada.
2. Defina o comportamento que não pode mudar.
3. Peça um plano antes da alteração.
4. Revise o diff e execute os testes existentes e novos.

## Exercício 4 — Depuração

1. Descreva o comportamento observado e o esperado.
2. Forneça apenas logs e trechos necessários, sem dados sensíveis.
3. Peça hipóteses e uma forma de verificar cada uma.
4. Confirme a causa antes de aplicar a correção.
