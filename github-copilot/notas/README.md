# Notas de estudo — GitHub Copilot

Registre aprendizados próprios, exemplos mínimos e diferenças entre o que a ferramenta sugeriu e o que foi validado.

## Modelo de nota

### Tema
Data e link da documentação oficial consultada.

### Conceito
Explique com suas palavras, sem copiar a documentação inteira.

### Experimento
Contexto usado, prompt, resultado esperado e resultado observado.

### Validação
Testes, inspeção do diff, comportamento observado e limitações.

### Conclusão
O que funcionou, o que falhou e o que você faria diferente.

## Boas práticas

- Nunca incluir tokens, senhas, dados pessoais ou código confidencial da empresa.
- Não registrar uma sugestão como fato sem verificá-la.
- Identificar conteúdo gerado por IA que ainda não foi revisado.
- Preferir exemplos pequenos e reproduzíveis.
